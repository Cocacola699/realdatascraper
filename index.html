Scraping tips

Records are drawn by JavaScript, so a plain requests.get() of this file will not contain them. Use Playwright or Selenium to render the page first, or in DevTools choose Copy > Copy outerHTML and parse the saved file. Then try: soup.select("article.record-card") and read card["data-id"], data-name, data-value and so on. Table rows use tr.record-row with the same attributes.

Data belongs to the sources listed above; check each source's terms before reusing it.
